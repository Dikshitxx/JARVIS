# fonts

## Purpose

Bundled local font assets loaded by frontend/app/layout.tsx.

## Files

- `GeistMonoVF.woff` - Variable Geist monospace font.
- `GeistVF.woff` - Variable Geist sans font.

## Execution and connections

Loaded at frontend build/runtime by next/font/local.

GeistSans and GeistMono are exposed through CSS variables.

See the [architecture guide](../../../docs/architecture.md) for the end-to-end flow and [folder map](../../../docs/folder-map.md) for repository-wide navigation.
